# Daily Schedule

用一句话管理 **Google Calendar 日程**与 **Todoist 待办**的 AI 插件 / Agent Skill。

告诉它你要做什么、什么时候做、何时截止以及优先级，它会按规则选择目标应用，执行操作并核验结果。

## 基本功能

- **所有任务 → Todoist + Google Calendar**：每个任务保留一个待办，并且必须在日历中展示；不再把一天内或无截止的任务排除在日历外。
- **跨天截止任务 → Todoist + 全天周期日程**：距离截止超过 24 小时，Calendar 顶部显示从开始日到截止日的全天条带，Todoist 保留一个可勾选待办，类似“本周任务”。
- **日程 → 仅 Google Calendar**：会议、课程、预约、比赛等明确日程只创建普通 Event；不生成 Todoist 待办，不需要打勾完成。移动日程、设置重复或说“会议结束了”也不会自动创建任务。
- **任务 + 执行时段 → 一个待办 + 关联时间块**：Todoist 记录要完成的事，Calendar 记录何时做；符合跨天规则时再有一个周期概览条目，分别关联。
- **普通任务的日历展示**：无执行时段、也不需要跨天周期时，用计划执行日或截止日的透明全天条目；均未给出时，今天显示“未安排任务”，Todoist 不因此增加虚构日期。
- 支持查询、新增、修改、延期、优先级调整、完成、恢复未完成和删除。
- 区分执行日期与最晚截止日期，避免移动日程时误改任务截止。
- 支持重复事项、冲突检查、防止重复创建、跨应用关联和操作后核验。
- 跨天条目设为“有空”，不会占用整周空闲时间；截止、标题、优先级与完成状态在相关聊天指令执行时同步。
- **明确指令直接执行**，包括删除；只有目标或必要信息不明确时才询问。宿主平台权限提示仍由平台控制。

## 使用示例

选择插件，或在支持 Skill 的环境中使用 `$daily-planner`，然后输入：

```text
今天下午五点前交报告，优先级高。
```

建立一个 Todoist 待办，加今天的透明全天任务条目；截止时刻写入描述，不编造执行时间段。

```text
本周日之前完成课程报告，优先级高。
```

如果距离截止超过 24 小时，同时建立一个 Todoist 待办和一个跨天全天日程。比如周二说“周五前交报告”，日历显示周二到周五的全天条带，不是连续占用四天的忙碌时间。

```text
明天下午三点到四点开会。
```

只建立一个 Google Calendar 普通日程，Todoist 不新增任何待办，也不需要勾选完成。

```text
日程：明晚七点到九点写报告，不要待办。
```

用户已明确将它定义为日程，因此也只建立 Calendar Event，不因“写报告”三个字转成任务。

```text
买电池。
```

Todoist 保留无日期待办；Calendar 今天显示“[未安排任务] 买电池”，并注明今天只是收集展示日。

```text
周五前交报告，明晚七点到九点写，优先级高。
```

建立一个 Todoist 报告待办，以及一个 Calendar 写作时间块，并记录关联。若距离截止超过 24 小时，再建立一个透明的全天周期条目；Todoist 仍只有一个待办。

```text
把写报告改到晚上八点到十点，截止日期不变。
报告截止日期延后两天。
报告完成了。
删除下周三的组会。
查看今天的任务、本周截止事项和逾期任务。
```

## 安装与连接

这个仓库提供流程规则和插件配置，**不包含你的账号授权**。每位使用者都需要在自己的宿主中连接 Google Calendar 和 Todoist: To Do List & Calendar，并具备所需读写权限。

### 作为插件使用

1. 从本仓库 Releases 下载 ZIP，或按下面的方法构建安装包。
2. 在支持自定义插件导入的 ChatGPT / Codex 宿主中导入。如果账号提供 Plugin Creator，可让其使用该 ZIP 创建你自己的私有插件。
3. 根据宿主提示安装、连接两个应用。
4. 首先输入“检查日历与待办连接，不创建内容”，再输入真实操作指令。

插件导入入口、工具可用性和授权流程取决于你的账号与平台。不要把本仓库 ZIP 当作任意 ChatGPT 账号都支持的一键安装链接。

### 作为本地 Agent Skill 使用

将 `skills/daily-planner` 整个目录复制到项目的 `.agents/skills/daily-planner`，然后在支持该目录的 Agent 中重新加载技能。支持显式调用的环境可使用 `$daily-planner`。

你仍需要配置或连接相应工具；复制 Skill 不会自动授权账号或安装连接器。其他支持 Agent Skills 的客户端需要适配其工具名称和能力。

## 构建安装包

需要 Python 3.9+，无需第三方依赖。在仓库目录运行：

```sh
python scripts/build.py
```

生成 `dist/daily-schedule-0.3.0.zip`。脚本检查 JSON 配置、JSON 格式的 YAML 元数据、技能引用、应用声明、图标、常见凭据模式以及归档完整性。结构检查不能替代真实日程与待办的行为测试。

跨天日期计算与边界测试：

```sh
python -m unittest discover -s tests -v
```

日期计算脚本可独立运行，不写入任何服务：

```sh
python skills/daily-planner/scripts/task_period.py --display --now 2026-10-15T12:00:00+08:00 --deadline 2026-10-18
```

该例显示 10 月 15 日至 18 日，Calendar 的排他结束值为 `2026-10-19`。

## 默认设置和运行边界

- 默认使用中文、北京时间 `Asia/Shanghai`、Todoist 收件箱和 Google 主日历；可在指令中指定其他目标与时区。
- 跨天判断严格使用大于 24 小时；日期级截止按当天结束计算。该条件只决定是否用跨天条带，不决定任务是否进入日历。只有执行日期时使用该日的单日任务条目。
- 周期开始日保持不变，延期截止会延长关联的周期条目；具体执行时间块保持不变。完成待办后，周期标题标为“已完成”，保留历史记录。
- 新规则应用于本次创建或修改的任务；更新版本或查询任务不会自动批量迁移全部旧待办。可明确要求“把现有本周任务补到日历”。
- 插件在收到聊天指令后执行；不在后台持续运行，不监听应用变化，也没有离线写入队列。
- 提醒由对应应用负责；截止日期、提醒等功能受工具与账户支持情况限制。
- Google Calendar、Todoist 的已有集成功能可能也会显示任务；插件会检查并避免不必要的重复，但不会修改你原来的集成设置。
- 手机 ChatGPT、网页 ChatGPT、桌面 Codex、本地 Codex 的写入能力需要分别验证。当前未宣称四端真实写入全部通过。
- 日期计算与展示选择有 21 个本地自动化测试；35 个行为验收场景仍是测试规格，不代表已全部运行。服务连接只读检查来自先前版本，v0.3.0 尚未执行线上写入验收。

## 文件说明

- `plugin.json`：便携插件声明，展示名为 Daily Schedule，内部标识为 `daily-planner`。
- `.app.json`：两个已有应用的公开标识，不是令牌，不包含作者的账号授权。
- `.codex-plugin/plugin.json`：Codex 兼容声明。
- `skills/daily-planner/SKILL.md`：分类、日期、执行和结果核验规则。
- `skills/daily-planner/references/`：字段适配、平台说明及行为验收场景。
- `skills/daily-planner/scripts/task_period.py`：无第三方依赖的跨天阈值及全天日期计算器。

GitHub 公开源码和发行包 **不等于已在 OpenAI 公共插件目录上架**。本包使用已有应用绑定；若准备向公共目录提交，需按该目录要求另外准备合规连接配置与提交材料。
